## How to run application

First of all, clone this repository with `git clone ...`

Then enter the backend project with cd ./chat_app/

-   Here run `composer install`
-   and `npm install`

Then enter the frontend part of the project with cd ../chat_app_front

-   Also run `npm install`

After installing all dependencies, run both backend and frontend projects with:

-   in chat_app root directory:
-   `php artisan serve`
-   `php artisan reverb:start`

-   in chat_app_front root directory:
-   `npm run dev`
